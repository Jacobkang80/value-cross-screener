# Google Apps Script 무료 순위 대시보드

AI·유료 데이터 API 없이 실제 종목과 시장 지표를 수집하고, 규칙 기반 요약·Google Sheets 저장·대시보드 표시를 수행합니다.

## 현재 동작

- 저PBR / 저PER / 고ROE 탭마다 KOSPI와 KOSDAQ 각각 상위 5개를 표시합니다.
- 선택한 지표만 양수여야 합니다. 다른 지표가 음수여도 제외하지 않습니다. 거래 가능한 보통주를 대상으로 하며 동률은 종목코드 순입니다.
- 골든크로스·이동평균선 필터와 모든 일봉 조회를 제거했습니다.
- 한 번의 실제 수집에는 시장 목록 2회와 VIX 1회, 총 3회만 외부 요청합니다.
- 열린 화면이 보이는 동안 10분마다 갱신하고, 결과 캐시는 10분입니다. 닫힌 화면용 예약 트리거는 설치하지 않습니다.
- 현재가·PBR·PER·ROE를 작은 표로 표시하며 선택한 정렬 열을 강조합니다. 모바일에서는 시장별 표를 세로로 배치합니다.
- 시장 PER·PBR은 KRX 공식값이 아닌 보통주 합산 참고값입니다.

## 2025 S&P 500 참고값

2025년 연평균이 아니라 **2025-06-30 기준** 후행 PER 27.88, PBR 5.06을 사용합니다. 참고 멀티플은 두 값을 곱한 141.07입니다. 수치 기준일과 출처 링크를 작은 글씨로 표시합니다.

출처: S&P Dow Jones Indices가 작성한 2025-12-31 S&P 500 팩트시트, 3페이지 Fundamentals 표와 각주. 해당 문서에 후행 PER·PBR의 기준일이 2025-06-30으로 명시되어 있습니다. 보관본: https://topforeignstocks.com/wp-content/uploads/2026/01/SP-500-Factsheet-Dec-31-2025.pdf

시장별 집계 방식과 시점이 달라 직접적인 적정가 비교값으로 쓰지 않습니다.

## 설정과 배포

1. Code.gs의 VC_BOOK_ID를 데이터 저장용 스프레드시트 ID로 설정합니다.
2. setup을 실행하고 Google 최초 권한을 검토·승인합니다.
3. 본인 실행·본인 접근으로 웹앱을 배포합니다.
4. 실제 데이터와 저장 완료 시각을 확인합니다.

실제 프로젝트는 기존 본인 전용 웹앱 URL을 유지합니다. 공개 저장소에는 개인 스프레드시트 ID를 넣지 않습니다.

## 소스와 검증

Code.gs는 서버 코드와 임베드된 화면을 포함합니다. 화면 편집은 Index.html에서 하고 아래 명령으로 Code.gs에 반영합니다.

```sh
node apps-script/build-html.mjs
node --test apps-script/gas.test.mjs
```

테스트 8개는 외부 요청 3회 제한, 상위 5개 정렬, 선택 지표 양수 필터, 캐시, 정렬별 저장과 일별 중복 방지, 날짜·종목코드 보존, 장애 시 이전 결과, 부분 실패, 화면 구문과 골든크로스 제거를 검증합니다. Google 서비스 모형을 사용하는 테스트이며 실제 실행 검증과 구분합니다.

## 저장 구조

새 순위는 VC_순위, VC_순위스냅샷, VC_순위로그에 저장합니다. VC_시장은 시장 참고값을 저장합니다. 날짜·종목코드는 텍스트로 보존하며 거래일·정렬·코드로 갱신합니다. 과거 후보·일봉 기록은 보존하지만 새 일봉을 수집하거나 저장하지 않습니다.

공급자 시세 지연과 무료 Google 계정·외부 서비스의 호출 제한이 적용됩니다. PER·PBR·ROE의 정확한 결산기간은 공급자가 제공하지 않습니다.
