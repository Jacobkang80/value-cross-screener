# Google Apps Script 무료 실행판

AI 또는 유료 데이터 API 호출이 없습니다. 웹앱을 열면 선택한 정렬의 실제 시세를 수집하고, 코스피·코스닥 각 상위 10개만 일봉을 확인합니다. 규칙 기반 요약과 대시보드를 생성하고 Google Sheets에 저장합니다. 열린 페이지는 10분마다 갱신하며 결과 캐시는 10분입니다. 닫힌 동안 실행되는 예약 트리거는 설치하지 않습니다.

## 설정과 배포

1. Apps Script 프로젝트에 Code.gs를 넣고 VC_BOOK_ID를 본인의 데이터 저장용 스프레드시트 ID로 설정합니다.
2. setup 함수를 한 번 실행합니다. Google 최초 실행 권한은 직접 검토하고 승인해야 합니다. 요청 범위는 스프레드시트 접근 및 외부 웹 조회입니다.
3. setup 성공 후 웹앱으로 새 배포합니다. 본인 실행 및 본인 접근으로 시작하세요.
4. 웹앱을 열어 실제 수집·저장 상태를 확인합니다.

Google 최초 승인 전에는 실제 수집·저장·배포가 검증된 상태가 아닙니다. Node 테스트 6개는 Google 서비스 모형을 사용해 후보 제한, 저장, 캐시, 정렬별 데이터 분리, 중복 방지, 장애 시 이전 결과 유지와 HTML 스크립트 구문을 검증합니다.

## 저장 구조

기존 탭을 변경하지 않고 VC_후보, VC_시장, VC_일봉, VC_스냅샷, VC_로그 탭을 생성합니다. 후보는 거래일·정렬·종목코드, 일봉은 거래일·종목코드로 중복 없이 갱신합니다. 실행 이력은 추가 기록합니다. 요약은 언어 모델 없이 정해진 규칙으로 생성합니다.

## 제한

이평선은 완료 일봉 기준입니다. 한국시간 16:30 이전에는 당일을 제외합니다. ROE 기간과 수정주가 처리는 공급자 기준입니다. KRX 공식 PER·PBR은 미확보이며, 보통주 합산 참고값을 명확히 구분해 표시합니다. 무료 Google 계정과 외부 공급자의 호출·시간 제한은 적용되며 24시간 무제한 실시간 스트리밍은 아닙니다.

```sh
node --test apps-script/gas.test.mjs
```
