# Google Apps Script 무료 스크리너

AI·유료 API·일봉 조회 없이 시세와 분기 실적을 수집하고 규칙 기반 선별, 요약, Google Sheets 저장, 화면 표시를 수행합니다.

## 선별 기준

1. 거래 가능한 보통주에서 시가총액 **1조원 이상**을 먼저 선별합니다. 공급자의 marketSum은 **원 단위**이며 1,000,000,000,000원과 직접 비교합니다.
2. 기본 순위는 **PER > 0, PBR > 0**을 모두 요구합니다. 음수·0·미제공 지표는 제외합니다.
3. 기본 화면은 **고ROE**, KOSPI·KOSDAQ 각각 상위 5개입니다. ROE도 양수여야 합니다. 저PBR·저PER 탭도 같은 시총·PER·PBR 필터를 적용합니다. 동률은 시총 내림차순, 종목코드 순입니다.
4. 흑자전환은 별도 표입니다. 시총 1조원 이상·PBR 양수 조건은 유지하고 **PER 음수·미제공은 허용**합니다. 최근 실제 분기 영업이익 > 0, 전년 같은 분기 영업이익 < 0이며 직전 분기 실적까지 확인된 기업만 표시합니다. ROE순으로 시장별 최대 5개, 전체 전환 기업 수도 표시합니다.
5. PBR 음수 기업은 자본 회복 여부를 확인할 수 없으므로 기본·흑자전환 목록에서 제외합니다.

ROE가 자본과 순이익의 동시 음수로 높게 보이는 착시를 PBR 양수 필터로 방지합니다. 낮은 PER·PBR만으로 투자 적합성을 보장하지 않습니다.

## 분기 자료와 효율

- 시장 목록 2회와 VIX 1회로 기본 순위를 생성합니다.
- 이후 시총·PBR 필터를 통과한 기업만 네이버 분기 실적 API에서 조회합니다. 전체 상장사의 일봉은 조회하지 않습니다.
- financePeriodType=quarter, 종목코드 일치, isConsensus=N을 검증합니다. 추정치와 누적 실적을 분기 실적에 섞지 않습니다.
- 최근 실적분기의 정확한 직전 분기와 전년 같은 분기를 비교합니다. 영업이익 단위는 억원입니다.
- 실적 0은 적자로 보지 않습니다. 누락·구조 변경·HTTP 실패는 미확인으로 표시하고, 없는 값 대신 과거 분기를 임의로 선택하지 않습니다.
- 실제 분기 실적은 최대 6시간 재사용하며, Google 캐시가 비워져도 Sheets의 저장 사실을 재사용합니다. 오류는 5분 후 재시도할 수 있습니다. 외부 요청은 최대 25개씩 묶습니다.
- 기본 순위 화면을 먼저 표시한 뒤 분기 표를 채웁니다. 회사마다 최근 제공 실적분기가 다를 수 있습니다. 공급자 업데이트가 지연되면 발표된 최신 공시가 아직 포함되지 않을 수 있습니다.
- 연결·별도 구분과 ROE의 결산기간은 공급자 기준이며 개별 기업의 공시 원문과 차이가 있을 수 있습니다.

화면이 보이는 동안 10분마다 갱신하고 기본 시세 결과는 10분 재사용합니다. 닫힌 화면용 예약 트리거는 설치하지 않습니다. 무료 Google 및 데이터 공급자의 사용 한도는 적용됩니다.

## 시장 참고값

시장 PER·PBR은 전체 보통주 중 양수 지표별 Σ시총 ÷ Σ(시총/지표)로 계산합니다. 선별한 대형주만의 평균이나 KRX 공식 지수값이 아닙니다.

S&P 500 참고 멀티플은 **2025-06-30** 후행 PER 27.88 × PBR 5.06 = 141.07입니다. 2025년 연평균이 아닙니다. 출처: S&P DJI 2025-12-31 팩트시트 3페이지 및 각주, 보관본 https://topforeignstocks.com/wp-content/uploads/2026/01/SP-500-Factsheet-Dec-31-2025.pdf

VIX의 ‘14 미만: 과열 주의’는 사용자가 정한 참고 기준입니다. VIX 자체는 S&P 500의 예상 변동성을 나타냅니다.

## 설정과 코드

1. Code.gs의 VC_BOOK_ID를 데이터 저장용 스프레드시트 ID로 설정합니다.
2. setup 실행 후 최초 Google 권한을 검토·승인합니다.
3. 본인 실행·본인 접근으로 웹앱을 배포합니다.
4. verifyTurnarounds 함수로 전체 분기 조회를 미리 실행·확인할 수 있습니다.

공개 저장소에는 개인 스프레드시트 ID를 넣지 않습니다. 기존 웹앱 URL과 비공개 접근 설정을 유지합니다.

화면은 Index.html에서 편집하고 임베드한 Code.gs를 갱신합니다.

```sh
node apps-script/build-html.mjs
node --test apps-script/gas.test.mjs
```

테스트 12개는 시총 경계값·PER/PBR 필터·정렬, 실제/추정 분기 분리, 누락 판정 보류, 전년/직전 분기 비교, PER 음수 허용, 25개 요청 묶음, 캐시·Sheets 재사용, 오류 처리, 화면 렌더링, JSON 분할, 날짜·코드 보존을 검증합니다. 모형 테스트와 실제 Google 실행은 구분합니다.

## 저장 구조

- VC_선별순위 / VC_선별스냅샷 / VC_선별로그: 새 기준 순위와 선별 대상
- VC_분기실적: 종목·실적분기별 비교 값, 출처·조회시각·상태
- VC_흑자전환 / VC_흑전스냅샷: 흑자전환 판정 결과
- VC_시장: 전체 시장 참고 지표

과거 순위·후보·일봉 기록은 보존합니다. 새 일봉은 조회·저장하지 않습니다.

## 실제 실행 검증

2026-10-30 Google Apps Script 실행에서 시총 1조원 이상 KOSPI 211개·KOSDAQ 73개를 확인했습니다. PER/PBR 양수 기업은 각각 183개·53개이며 고ROE 기본 순위는 시장별 5개씩 저장했습니다. 분기 조회는 284/284개 성공, 전년 동기 대비 흑자전환은 시장별 8개씩 확인했습니다. 해당 실행에서 공급자가 실제 실적으로 구분한 최근 분기는 2026-06입니다. 2026-09 추정치는 판정에 사용하지 않았습니다. 결과는 이후 시세·실적 갱신에 따라 달라집니다.
